# Project 9: Encryption/Decryption Tool

A beginner-friendly Python cybersecurity project demonstrating:
- Symmetric file encryption and decryption using Fernet.
- SHA-256 file hashing.
- The difference between hashing and encryption.
- Basic encryption key management.

## How to run

1. Make sure Python is installed.
2. Install the required library:

    pip install cryptography

3. Open this folder in VS Code or Command Prompt.
4. Run:

    python crypto_tool.py

## Files

- crypto_tool.py - main program
- secret.key - encryption key used by the program
- sample.txt - test file
- requirements.txt - required Python library

## Important

The `secret.key` file is a secret. Do not share it publicly.
